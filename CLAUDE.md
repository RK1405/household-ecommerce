# CLAUDE.md — HomeHaat (household-ecommerce)

Demo ecommerce store for household items in India. Owner: Rama. Everything runs locally; nothing is deployed and no real emails or payments happen.
Read `README.md` first, especially the sections "Decisions & assumptions" and "Known gaps / next steps".

## Run
- `npm install && cp .env.example .env && npm start` → http://localhost:3000 (admin: /admin/login.html)
- `npm run reset` re-seeds `/data` (git-ignored, generated by `scripts/seed.js`).
- Tests: `npx playwright install chromium` once, then `npm run test:e2e`. The suite runs on port 3100, resets the data and writes `docs/test-report.md` and `docs/screenshots/`. Keep it at 37/37 passing.
- Demo logins: user@demo.com / User@123 · admin@demo.com / Admin@123.

## Stack and conventions
- Node 20+, Express 5 (CommonJS) on the server. Plain HTML/CSS and ES modules in the browser. No build step, no frontend framework, no native modules, no CDN: vendor libraries are served from node_modules under `/vendor/*`.
- Every page is its own `.html` file with its own script: storefront scripts in `public/js/pages/`, admin scripts in `public/admin/js/`.
- Shared UI lives in `public/js/components/`. Design tokens live only in `public/css/tokens.css`.
- Layering is routes → services → repositories. Only `src/repositories/*.repo.js` (one module per entity) touches storage, through `src/db/jsonStore.js`. Keep that boundary so MySQL or Salesforce can be swapped in. The schema is `db/mysql/schema.sql`; regenerate `seed.sql` with `node scripts/export-sql.js`.
- Payments go through the `PaymentProvider` interface in `src/services/payments/`. The dummy provider is used now; `razorpay.provider.js` is a stub with Razorpay-shaped methods.
- Emails go through `src/services/email.service.js`. Demo mode always writes to `storage/outbox`, never sends.
- Reviews and Customers are intentionally MOCK (`src/services/reviews|customers`), with interfaces and TODO adapters for MySQL and Salesforce.
- Chatbot flows live in `public/chatbot/flows.json` (rule-based, not AI).
- Indian context throughout: ₹ prices with en-IN formatting, GST-inclusive prices, 6-digit PIN codes, +91 mobile numbers, the list of Indian states.
- The store name "HomeHaat" is a placeholder set in CMS data (`data/cms.json`, seeded from `scripts/seed.js`).
